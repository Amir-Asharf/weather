🌤️ Weather App (Flutter + BLoC)
A clean and well-structured Flutter weather application that displays real-time weather data using an external API.
The app follows Clean Architecture principles and uses BLoC (Business Logic Component) for efficient state management.

Key Features:
⛅ Real-time weather data from external API

🌗 Dynamic UI that changes based on time (morning/night themes)

📍 Location-based weather detection

🧱 Built with BLoC pattern for scalable state management

🧼 Clean code architecture with separation of concerns
